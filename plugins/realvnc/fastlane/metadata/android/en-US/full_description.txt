An optional plugin for Vento, adding support for RealVNC's extensions to the RFB protocol.

It requires a RealVNC APK, either provided manually, or automatically downloaded and verified from Aptoide.

* UDP support.
* ZRLE2 encoding support.
* Support for newer RealVNC auth methods.
* Only supports direct connections, not cloud ones.

This app must be used with a matching Vento version. It does not have its own launcher icon, and is accessible via the main app.
