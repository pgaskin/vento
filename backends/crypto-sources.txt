# `third_party/gnutls` are unpacked from (`build.gradle` says why they are
# not submodules). Gradle's `fetchCryptoSources` reads this file, and so does
# `fetch-crypto-sources.py`, which the Linux Meson build runs to unpack a
# missing tree itself; both unpack the same way, so a tree is the same
# whichever did it.

# tarball), and `url`, once per mirror, tried in the order given.
